# Belita & Theodor — Convite de Casamento

Website estático responsivo actualizado com `Prob(3).pdf`.

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie o conteúdo para a raiz do repositório. `index.html` deve ficar na raiz e `assets/` ao lado.
3. No GitHub, abra **Settings → Pages**.
4. Escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e guarde.

## Correcção definitiva da abertura
- O envelope é agora uma camada fixa (`position: fixed`) que cobre o ecrã inteiro.
- O convite já fica carregado por trás do envelope, com a primeira frase no início real do documento.
- Ao tocar no selo, apenas se remove a camada do envelope. Assim, a frase «Com a Bênção de Deus e de seus Pais» fica imediatamente visível no topo, sem depender da rolagem ou do carregamento da imagem.
- O botão final abre https://convitin.com.br/matrimonio-3/

Substitua todos os ficheiros anteriores no GitHub, incluindo `index.html` e a pasta `assets`.
